# About Flowspace

Flowspace is a project and team collaboration SaaS platform. Teams use
Flowspace to organize tasks into boards, assign work to teammates, track
deadlines, and communicate progress in one place.

Flowspace was built for small to mid-sized teams (2 to 200 people) who want
something simpler than heavyweight enterprise project management tools.

Core features:
- Task boards (Kanban-style columns: To Do, In Progress, Done)
- Team member assignment and due dates
- File attachments on tasks
- Comments and activity history on each task
- Email and in-app notifications
- Basic reporting (tasks completed per week, overdue tasks)

Flowspace is accessible via web browser and has mobile apps for iOS and
Android.
